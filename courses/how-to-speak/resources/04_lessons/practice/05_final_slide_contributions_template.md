# 练习 5：最后一张幻灯片与结束语模板

> 对应章节：第 9 章 "如何结束"

---

## 目标
设计有力的演讲结尾，避免"谢谢"幻灯片，让听众带走核心信息。

---

## 理论回顾

### ❌ 不要做的事
- 不要放"谢谢"幻灯片
- 不要道歉（"时间不够了..."）
- 不要引入新信息
- 不要突然结束

### ✅ 要做的事
- 最后一张幻灯片展示你的核心贡献
- 结束语简洁有力
- 与主题相关
- 让听众带着核心信息离开

---

## 最后一张幻灯片模板

### 版本 A：贡献列表

```
# 我的核心贡献

1. [贡献1的简洁描述]
2. [贡献2的简洁描述]
3. [贡献3的简洁描述]

联系方式：[你的邮箱]
```

### 版本 B：愿景总结

```
# 未来愿景

[一句话描述你的愿景]

关键步骤：
- [步骤1]
- [步骤2]
- [步骤3]

让我们一起实现它。
```

### 版本 C：行动号召

```
# 下一步行动

你可以：
1. [行动1]
2. [行动2]
3. [行动3]

从今天开始。
```

## 结束语模板

### 模板 1：愿景式
> "我们的工作才刚刚开始。想象一个世界，在那里 [愿景]。今天，我们迈出了第一步。"

### 模板 2：回顾式
> "今天，我们讨论了 [主题]。关键在于 [核心信息]。记住这一点，你就能 [能力]。"

### 模板 3：挑战式
> "现在，轮到你了。你能 [挑战] 吗？我相信你可以。"

### 模板 4：故事式
> "让我用一句话总结：[核心信息]。就像 [类比] 一样，[寓意]。"

## 笑话使用指南（可选）

如果你决定在结尾讲笑话：

### ✅ 好的笑话标准
- [ ] 与主题相关
- [ ] 所有人都能理解
- [ ] 不会冒犯任何人
- [ ] 简短（30秒内）
- [ ] 你练习过，知道笑点在哪里

> "一个工程师和一个数学家同时看到一座美丽的房子。工程师说：'我想住在那里。'数学家说：'我想证明有人住在那里。'"
