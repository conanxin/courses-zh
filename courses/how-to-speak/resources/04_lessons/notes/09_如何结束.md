# 讲义 09 — 如何结束

> 对应视频：第 9 章 (53:06 - 56:35)
> 章节：如何结束 — 最后一张幻灯片与结束语 How to Stop: Final Slide, Final Words

## 核心概念

> **结束的两大要素：**
>
> 1. **最后一张幻灯片**：不要"谢谢"——要"贡献"
> 2. **结束语**：可以讲笑话，但必须与主题相关、必须用过两次

## 详细内容

### 一、最后一张幻灯片：不要"谢谢"

#### 为什么要避免"谢谢"幻灯片？

温斯顿的核心论断：

> "如果你放一张'谢谢'作为最后一张幻灯片，你就**把你刚刚做的演讲中的所有东西都吹走了**。"

**为什么"谢谢"幻灯片是有害的**：

| 问题 | 解释 |
|------|------|
| **告诉听众"我讲完了"** | 把他们从专注状态拉出 |
| **告诉他们"我想让你们回家"** | 暗示演讲不再重要 |
| **浪费最后一张幻灯片** | 听众记得"谢谢"而不是你的贡献 |
| **破坏了你的印象** | 最后印象 = 整个印象 |

**温斯顿的对比**：

> ❌ "谢谢" = 告诉老板"你的演讲很糟糕"
>
> ❌ "谢谢您的关注" = 彻底的无效关闭

#### 正确的最后一张幻灯片：贡献页

温斯顿的最后一张幻灯片长这样：

```
[一张图像]
标题："结论"（Conclusion）
编号项目 1：[核心贡献 1]
编号项目 2：[核心贡献 2]
编号项目 3：[核心贡献 3]
编号项目 4：[核心贡献 4]
```

**这张幻灯片的设计逻辑**：

1. **有图像**：让最后印象可视化
2. **有标题**："结论"——明确告诉听众"这是总结"
3. **编号项目**：让要点清晰、可拍照
4. **可带走**：听众拍照发朋友圈/同事——**这是你演讲的延伸**

**为什么听众会拍照**：

> "到最后，听众们把幻灯片拍下来——他们拍幻灯片——他们把幻灯片拍下来，对吧？——他们把幻灯片拍下来带走。"

**这意味着**：

- 你的最后一张幻灯片**会被人传阅**
- 它是你演讲的**永久纪念品**
- 它必须**传达你的核心贡献**

#### 贡献 vs 教学的区别

温斯顿的强调：

> "同样，因为我们说的是**说服型演讲**，而不是教学型演讲，那是关于**贡献**的。"

| 演讲类型 | 最后一张幻灯片应该 |
|----------|---------------------|
| **说服型**（求职、会议） | 你的**贡献** |
| **教学型**（讲座） | 关键**要点**或**下一步** |

### 二、结束语：笑话与原则

#### 笑话的"两必须"原则

**原则 1：笑话必须与主题相关**

> "它不能是午餐菜单上的任何笑话。它不能是与你的演讲没有任何关系的随机笑话。"

**温斯顿的标准**：

> "如果你要讲一个笑话，它必须**与你刚才讲的内容有关**。"

**反例**：

- 在 AI 演讲结尾讲一个关于"鸡为什么过马路"
- 在求职报告结尾讲一个关于"夫妻吵架"
- 在学术会议讲一个关于"工程师、物理学家、数学家"——除非你**在演讲中提到了他们的思维方式**

#### 原则 2：笑话必须用过两次

**温斯顿的核心规则**：

> "任何一个笑话都必须在它要出现的地方**至少出现两次**才能用。"

**温斯顿再次强调**：

> "让我再说一遍，因为这是重要的。一个笑话都必须在它要出现的地方**至少出现两次**才能用。"

**为什么**？

- 第一次讲：测试效果，记录反响
- 第二次讲：确认效果，**确定它适合这个场合**
- 只有用过两次的笑话才能**保证不冷场**

**实践流程**：

```
笑话出现 1 次（在某次演讲中讲）
    ↓ 观察反响
笑话出现 2 次（在类似场景中再讲）
    ↓ 确认效果
可以正式使用（保证不冷场）
```

#### 工程师、物理学家、数学家的笑话

温斯顿自己常用的笑话（用过无数次）：

> "一位工程师、一位物理学家和一位数学家被困在一座着火的旅馆里。他们站在窗边，看着下面三楼的窗台。
>
> 工程师从窗户跳了出去，掉到了窗台上——撞到了窗台上——断了一条腿。
>
> 物理学家从窗户跳了出去，撞到了窗台上，断了一条腿。
>
> 数学家从窗户跳了出去，**飘走了**。
>
> 他们后来又凑到一起，工程师说：'我把这次经历算作**零**。'
> 物理学家说：'我把这次经历算作 **e**。'
> 数学家说：'我把这次经历算作 e，但**加了一个负号**。'"

**为什么这个笑话与主题相关**：

- 温斯顿的演讲主题是**抽象数学和工程问题**
- 笑话本身就是**抽象数学和工程问题**
- 这是一个**自指**的笑话——和"如何演讲"本身的自指性呼应

**为什么这个笑话有效**：

- **让人笑**：反差 + 简洁
- **让人思考**：数学家在想什么？
- **与主题相关**：是关于"如何思考"的话题
- **用过无数次**：保证不会冷场

### 三、温斯顿对最后幻灯片的演示

温斯顿在演讲现场展示了**反例幻灯片**：

**反例 1**：标准"谢谢"幻灯片
- ❌ 只有"谢谢"两个字
- ❌ 没有贡献
- ❌ 浪费最后印象

**反例 2**："谢谢您的关注"
- ❌ 同样空洞
- ❌ 加上"您的关注"——更糟（暗示听众之前没关注）

**反例 3**：其他变体
- ❌ 任何只表达感谢的版本都无效

**对比：好的最后幻灯片**

```
[核心图像]
标题：贡献

1. [贡献 1]
2. [贡献 2]
3. [贡献 3]
4. [贡献 4]
```

### 四、结束语的力量

**为什么结束语很重要**：

- **峰终定律**（Peak-End Rule）：人们记住的是**最高峰**和**最后时刻**
- 你的最后 30 秒 = 听众带走的最后印象
- 这个印象 = 听众对你研究的**最后评价**

**好的结束语应该**：

| 维度 | 标准 |
|------|------|
| **简洁** | 不超过 30 秒 |
| **有力** | 一句话能"砸"在地上 |
| **可记忆** | 听众能复述给别人 |
| **呼应主题** | 与开头/中间呼应 |
| **不冷场** | 用过的笑话/金句 |

**三种结束语模板**：

#### 模板 1：总结型

> "今天我们讲了 X、Y、Z。希望 [它们如何改变你的实践]。"

#### 模板 2：行动召唤型

> "接下来一周，我希望你们 [具体行动]。让我们把这变成现实。"

#### 模板 3：共鸣型

> "最后我想回到 [开头的故事/类比]。因为 [为什么它仍然重要]。"

### 五、温斯顿的实例：他自己怎么结束

温斯顿在课程结尾用了一个**共鸣型结束**：

> "这个演讲本身就是'如何演讲'的完整例子。
>
> - 我用了**循环强化**
> - 我用了**建围栏**
> - 我用了**语言标点**
> - 我用了**问问题**
> - 我向你们做了**赋能承诺**
> - 我做了**贡献幻灯片**（不是"谢谢"！）
> - 我用了**黑板**
> - 我用了**道具**——自行车轮子、钢球、手稿
> - 我用了**温斯顿之星**作为重复的视觉符号"

**这个结束的精妙之处**：

1. **自指**：演讲本身是"如何演讲"的实例
2. **循环强化**：把全课的要点收尾再讲一遍
3. **没有"谢谢"**：最后一句是鼓励而非感谢
4. **激励**：告诉听众他们还有机会成长

### 六、温斯顿的"软"结尾：鼓励

温斯顿的最后一段话：

> "你们中有许多人还没学会如何去演讲。事实上，**没人真正学过**，因为没有地方去学它。
>
> 但这意味着你们**有许多机会**去做演讲，去学习，去练习，去发现哪个技巧对你们有用。
>
> 所以你们的'演讲武器库'还很薄弱，所以**给你们自己一个机会，去做它**。"

**为什么这个结尾有效**：

- **承认不完美**：没人学过——减少听众压力
- **强调可能性**：你们有很多机会——给听众希望
- **行动召唤**：给自己一个机会——推动行动
- **温暖而非总结**：不是"以上就是"，而是"你可以的"

## 实践建议

### 最后一张幻灯片的 7 步设计

1. **写 3-5 个核心贡献**：不是教学要点，是**贡献**
2. **为每个贡献写 1 句话**：每句话不超过 15 字
3. **选一个能代表你工作的图像**：放在标题旁
4. **标题写"贡献"或"Conclusion"**：明确告诉听众这是总结
5. **用编号列出**：1、2、3、4——清晰可拍照
6. **不要写"谢谢"**：永远不要
7. **测试可读性**：从后排看是否清晰

### 笑话素材库建设

**建立你的"笑话候选"清单**：

| 笑话 | 主题 | 用过的场合 | 效果 |
|------|------|------------|------|
| 笑话 1 | | | |
| 笑话 2 | | | |
| 笑话 3 | | | |

**只有用过 2 次以上的笑话才能进入你的"可信笑话库"**。

### 结束语的 3 选 1

每次演讲前，从三种模板中选一个：

- **总结型**：回顾要点
- **行动召唤型**：推动具体行动
- **共鸣型**：回到开头的元素

**不要混用**——选一个，专注做透。

### 自检清单

下次演讲前检查：

- [ ] 最后一张幻灯片是**贡献**，不是"谢谢"
- [ ] 贡献**用编号列出**，可拍照
- [ ] 有**图像**增强记忆
- [ ] 结束语**不超过 30 秒**
- [ ] 笑话（如果要讲）**用过两次以上**
- [ ] 笑话**与主题相关**
- [ ] 没有"谢谢您"

## 练习题

1. **反例收集**：找 5 张别人演讲的"谢谢"幻灯片，分析它们浪费了什么
2. **贡献幻灯片练习**：为你下次演讲设计一张"贡献页"
3. **笑话清单练习**：列出 5 个你听过的笑话，分类：与主题相关/无关
4. **"两次"练习**：选一个你想用的笑话，找机会讲 2 次，记录效果
5. **结束语练习**：为你的下次演讲写三种结尾（总结型/行动召唤型/共鸣型），选一个
6. **峰终定律应用**：回忆一个你印象最深的演讲，它的最高峰和最后时刻是什么？
7. **温斯顿自指练习**：让你的下次演讲**本身就是关于演讲技巧的实例**
