## Chapters / 章节

### Ch.1 Introduction / 开场
- **Time / 时间:** 00:16 - 03:11 (2m 55s / 2分55秒)
- **Key Point / 核心:** The importance of speaking skills, analogy to military justice code
- **学习目标:** 理解为什么演讲技能至关重要

### Ch.2 Rules of Engagement / 参与规则
- **Time / 时间:** 03:11 - 04:15 (1m 04s / 1分04秒)
- **Key Point / 核心:** Success = audience gains new capability; empowerment promise
- **学习目标:** 掌握演讲的核心目标设定

### Ch.3 How to Start / 如何开场
- **Time / 时间:** 04:15 - 05:38 (1m 23s / 1分23秒)
- **Key Point / 核心:** No jokes, no thanks, no apologies; start with a promise
- **学习目标:** 学会强有力的开场方式

### Ch.4 Four Sample Heuristics / 四个启发式方法
- **Time / 时间:** 05:38 - 10:17 (4m 39s / 4分39秒)
- **Key Point / 核心:** Cycling, build a fence, verbal punctuation, ask a question
- **学习目标:** 掌握四个基础演讲技巧

### Ch.5 The Tools: Time and Place / 工具之一：时间与地点
- **Time / 时间:** 10:17 - 13:24 (3m 07s / 3分07秒)
- **Key Point / 核心:** Best time is 11 AM; avoid before meals; choose venue carefully
- **学习目标:** 了解环境因素对演讲效果的影响

### Ch.6 The Tools: Boards, Props, and Slides / 工具之二：黑板、道具与幻灯片
- **Time / 时间:** 13:24 - 36:30 (23m 06s / 23分06秒)
- **Key Point / 核心:** Boards for derivation, props for demonstration, slides sparingly
- **学习目标:** 学会选择合适的演讲工具，制作有效的幻灯片

### Ch.7 Informing: Promise, Inspiration, How to Think / 信息型演讲
- **Time / 时间:** 36:30 - 41:30 (5m 00s / 5分00秒)
- **Key Point / 核心:** Structure: Promise → Inspire → How to Think
- **学习目标:** 掌握信息型演讲的核心结构

### Ch.8 Persuading: Oral Exams, Job Talks, Getting Famous / 说服型演讲
- **Time / 时间:** 41:30 - 53:06 (11m 36s / 11分36秒)
- **Key Point / 核心:** Oral exams (depth), job talks (contributions), fame (symbol + slogan)
- **学习目标:** 掌握说服型演讲的技巧

### Ch.9 How to Stop: Final Slide, Final Words / 如何结束
- **Time / 时间:** 53:06 - 56:35 (3m 29s / 3分29秒)
- **Key Point / 核心:** No "thank you" slide; final slide shows contributions; strong closing
- **学习目标:** 学会有力的演讲收尾

### Ch.10 Final Words: Joke, Thank You, Examples / 结束语
- **Time / 时间:** 56:35 - 01:00:28 (7m 07s / 7分07秒)
- **Key Point / 核心:** Engineer vs. mathematician joke; thanks; concrete examples
- **学习目标:** 通过实例巩固所学技巧
