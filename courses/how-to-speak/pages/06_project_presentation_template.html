温斯顿技巧自查表

在准备汇报时，检查你是否应用了以下技巧：

开场

  • [ ] 赋能承诺（听众将获得什么能力？）
  • [ ] 没有笑话、感谢或道歉
  • [ ] 直接切入主题

内容

  • [ ] 循环强化（核心概念至少提到 3 次）
  • [ ] 建围栏（区分你的工作与现有工作）
  • [ ] 语言标点（清晰的过渡语）
  • [ ] 提问（至少 1 个引发思考的问题）

视觉

  • [ ] 幻灯片少字、大图
  • [ ] 每页一个核心信息
  • [ ] 标题就是结论
  • [ ] 没有"谢谢"幻灯片

结尾

  • [ ] 最后一张幻灯片展示核心贡献
  • [ ] 结束语简洁有力
  • [ ] 与主题相关

温斯顿之星

  • [ ] 符号（代表工作的视觉/语言符号）
  • [ ] 口号（一句话概括）
  • [ ] 惊讶点（出乎意料的结果）
  • [ ] 突出想法（最核心观点）
  • [ ] 故事（承载信息的叙事）
